تحديث أيقونة WEBTECHIX بالشعار الأصلي

ارفعي الملفات الأربعة التالية إلى جذر مستودع GitHub نفسه، بجوار index.html:
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

هذه الأيقونات مأخوذة من صورة الشعار الأصلية المرسلة، مع تغيير المقاس فقط دون إعادة تصميم أو قص.

مهم:
1) عند رفع الملفات اختاري استبدال manifest.webmanifest و sw.js إذا سأل GitHub.
2) لا تحذفي index.html أو styles.css أو app.js أو data.json.
3) بعد Commit انتظري اكتمال GitHub Pages.
4) افتحي رابط الموقع في Chrome، ثم امسحي بيانات الموقع/الكاش أو جرّبي نافذة خاصة قبل إعادة التثبيت.
