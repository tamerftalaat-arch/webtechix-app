# WEBTECHIX PWA
هذه نسخة أولية قابلة للتثبيت كتطبيق ويب (PWA)، وليست APK ولا نسخة متجر.

## الملفات
- index.html: واجهة التطبيق
- data.json: نسخة احتياطية من البيانات
- app.js: تحميل البيانات وعرضها
- manifest.webmanifest: إعدادات التثبيت
- sw.js: التخزين المؤقت والعمل الأساسي دون اتصال

## مهم قبل النشر
1. ارفعي محتويات هذا المجلد إلى استضافة ثابتة تدعم HTTPS (مثل GitHub Pages).
2. افتحي رابط الموقع من Chrome على Android.
3. اختاري «تثبيت التطبيق» أو من قائمة Chrome «إضافة إلى الشاشة الرئيسية».
4. اختبري التطبيق على الهاتف.

يحاول التطبيق أولًا قراءة صفحة بيانات Blogger:
https://webtechix.blogspot.com/p/webtechix-app-data.html
ويبحث عن العنصر ذي المعرّف webtechix-app-data. إذا منع المتصفح الطلب بسبب CORS، يستخدم data.json المرفق. عندها يجب تحديث data.json عند تغيير البيانات إلى أن نثبت وسيلة الربط المباشر.

روابط الخدمات والباقات الحالية # هي روابط مؤقتة؛ أزرارها تفتح واتساب برسالة استفسار.
